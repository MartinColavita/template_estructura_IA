# Índice de la sección diseno

Lo genera `python -I bin/puerta-skills.py --generar` con la primera oración de cada descripción: no se edita a mano.

- `cerebro-architect-ui`: Analiza maquetas y prototipos visuales del proyecto (exportaciones de Stitch en HTML o PNG, Figma, HTML a mano) y los traduce a especificaciones técnicas, mapeando CADA control a su regla de negocio del OKF con wikilink.
- `cerebro-mockup-design`: Armar o mejorar un HTML o prototipo de pantalla hecho a mano con el design system del proyecto.
- `cerebro-ppt-generator`: Habilidad para generar presentaciones interactivas en HTML del proyecto.
