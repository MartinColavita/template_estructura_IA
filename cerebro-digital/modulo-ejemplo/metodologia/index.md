# 02 - Metodología (modulo-ejemplo)

Este directorio es el **Contrato del Equipo** para el desarrollo del módulo. Acá documentamos el
*cómo trabajamos* en el día a día para construir las funcionalidades.

## ¿Qué vas a encontrar acá?
* **Workflow y QA:** cómo es el ciclo de vida de una tarea, cómo se testea y cómo se aprueba (Definition of Done). El DoR/DoD de los tickets está en `tablero/conocimiento/definicion-preparado-terminado.md`.
* **Convenciones del equipo:** estrategia de ramas (git), estándares de revisión y uso de SDD. Ramas, commits y Merge Requests contra Azure DevOps: [[convenciones-git]].
* **Manejo de trabajo:** interacción entre desarrollo y QA, gestión de incidencias, etc.

> **Regla de oro:** esta carpeta dicta las normas operativas del equipo, asegurando la calidad y homogeneidad en nuestro proceso de entrega. El **método de desarrollo** (TDD con evidencia, revisión, entrega) vive en la skill `desarrollo`; acá van las convenciones propias de este equipo.

## Contenido de esta carpeta

* [[convenciones-git]]: nombres de ramas, mensajes de commit, Merge Requests y cómo se vinculan los repositorios de código con el tablero.
