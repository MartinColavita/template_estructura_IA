# entregables/disenos/

Mockups HTML **validados** y promovidos desde `borrador/disenos/`.

- `logo.png`: el logo de la organización/producto que usan las presentaciones
  (`cerebro-ppt-generator` lo referencia como `../disenos/logo.png`). El que viene con el
  template es un **placeholder**: reemplazalo.
- Cada mockup sigue el design system de `cerebro-mockup-design` (tokens en `:root`, sin emojis,
  badges `FAKE` / `Sin regla` en todo control sin regla que lo respalde).
- Una maqueta decide el comportamiento de pantalla **sólo si una ficha funcional la cita** en su
  `fuente_maqueta`; una maqueta «propuesta» que ninguna ficha cita no decide nada.
