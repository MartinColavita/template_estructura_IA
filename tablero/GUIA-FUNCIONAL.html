Conectá tu PC con Azure

Se hace una sola vez. Elegí una opción.
Opción A — con token
  1. Conseguí tu token en Azure.
    Azure DevOps → tu foto (arriba a la derecha) → Personal Access Tokens → New Token. Nombre a gusto, vencimiento 90 días, permiso Work Items (elegí Read & Write si vas a crear/editar). Create → copiá el token (se muestra una sola vez).
  2. Abrí la terminal (Windows: buscá "Terminal" o "PowerShell").
  3. Pegá este comando en una sola línea, reemplazando las 2 partes en <...>, y Enter:
    claude mcp add azure-devops --env AZURE_DEVOPS_ORG_URL=https://dev.azure.com/<tu-organizacion> --env AZURE_DEVOPS_AUTH_METHOD=pat --env AZURE_DEVOPS_PAT=<pega-tu-token> -- npx -y @tiberriver256/mcp-server-azure-devops
Las 2 partes a reemplazar: <tu-organizacion> = el nombre de tu organización en Azure · <pega-tu-token> = el token del paso 1. Nada más: te conectás directo a Azure en la nube. No necesitás instalar ningún certificado (Azure en la nube ya tiene uno público válido).
Seguridad: este comando guarda tu token en la configuración de tu PC. Es lo más simple. Si preferís no guardar ningún token, usá la pestaña "Con tu cuenta". El token es como una contraseña: si se filtra, revocalo en Azure y creá uno nuevo.
Opción B — con tu cuenta
  1. Instalá Azure CLI una vez (pedíselo a Infraestructura, o de la página de Microsoft). Azure CLI es la herramienta de línea de comandos de Azure.)
  2. Entrá con tu cuenta: se abre el navegador y entrás con tu usuario de {{ORGANIZACION}}.
    az login
  3. Pegá este comando en una sola línea, reemplazando <tu-organizacion>:
    claude mcp add azure-devops --env AZURE_DEVOPS_ORG_URL=https://dev.azure.com/<tu-organizacion> --env AZURE_DEVOPS_AUTH_METHOD=azure-cli -- npx -y @tiberriver256/mcp-server-azure-devops
Ventaja: no hay token que guardar ni renovar. Cuando expira la sesión, volvés a hacer az login y listo.
