# Ejemplos — índice

Casos resueltos **de pobre a profesional**: el "antes" (lo que llega mal escrito) y el "después" (el work item completo, campo por campo). Sirven de modelo a imitar. Agnósticos; el dominio aparece solo como recuadro "Ejemplo (genérico)".

## Los ejemplos de esta carpeta

| Ejemplo | Muestra |
|---|---|
| [[ejemplo-tarea]] | Un pedido técnico pobre convertido en Tarea con objetivo, alcance, DoD y enlace Parent. |
| [[ejemplo-bug]] | Un bug "ver adjunto" convertido en reporte reproducible (Ambiente/Versión/Pasos/Esperado/Obtenido/Por qué), con tag y relacionadas. |
| [[ejemplo-habilitador]] | Una migración/reestructuración como Habilitador técnico: alcance origen→destino, criterios verificables (paridad de contrato), riesgos y DoD. |
| [[ejemplo-pipeline-ficha-a-arbol]] | **End-to-end del pipeline**: de una ficha del Cerebro Digital al árbol de tickets (Épica→Features→Historias) con traza doc↔ticket por referencia. |
| [[ejemplo-historia-4-bloques]] | **Historia "gold" con los 4 bloques** (Funcionalidad · Criterios en Gherkin · Reglas de negocio con referencia al OKF · Casos de uso), + documento fuente y el HTML pegable. Modelo para que sirva a Desarrollo y a Testing. |

## Ejemplos poblados en el historial

Además de estos, el `historial/` acumula **registros `gold`** (los tickets que se marcan como modelo) que la IA imita — ver [[INDICE]]. Son la mejor referencia de estilo por tipo/módulo.
